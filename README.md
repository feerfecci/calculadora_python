## Visão geral

O projeto implementa uma calculadora com interface gráfica, estruturada em funções e com componentes reutilizáveis. O foco está na clareza do código, na organização da aplicação e na construção de uma interface simples e intuitiva.

## Funcionalidades

- Operações aritméticas básicas: adição, subtração, multiplicação e divisão.
- Operação de módulo (`%`).
- Suporte à entrada de números decimais.
- Botão para limpar a expressão.
- Exibição da expressão e do resultado na própria interface.
- Interface gráfica com botões e esquema de cores personalizados.

## Como executar

### Pré-requisitos

- Python 3 instalado.
- Tkinter disponível na instalação do Python.

> O Tkinter geralmente já acompanha as instalações oficiais do Python para Windows.

### Instalação e execução

1. Clone o repositório:

```bash
   git clone URL_DO_REPOSITORIO
```

2. Acesse o diretório do projeto:

```bash
   cd nome-do-repositorio
```

3. Execute a aplicação:

```bash
   python calculadora.py
```

   No Windows, caso o comando `python` não seja reconhecido, utilize:

```bash
   py calculadora.py
```

## Conceitos aplicados

Durante o desenvolvimento, foram praticados os seguintes conceitos:

- Declaração e utilização de variáveis.
- Criação e chamada de funções.
- Manipulação de eventos de botões.
- Uso de `StringVar` para atualização dinâmica de informações na interface.
- Organização de elementos gráficos com `Frame`.
- Reutilização de componentes por meio de uma função para criação de botões.
- Aplicação de cores, fontes, dimensões e posicionamento de elementos.
